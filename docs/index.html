Observed decisions, not generated ones

Jev asks a narrower question than a general agent: given the elements the harness actually observed, which single operation advances the goal?

  • Targets are element refs from the latest snapshot; the executor never invents selectors, coordinates, or values.
  • One validated operation and target per cycle, consumed once; stale refs are re-observed, not acted on.
  • No screenshots in the loop; page text is capped near 6,000 characters and treated as untrusted data.
  • Free OpenCode Zen models first (muse-spark contributor), with a cheap OpenCode Go fallback for text.

Full reference — tools, loop, key resolution, limits — in the README.

Fast cycles, small bills

Bounded multiple-choice questions and text-only payloads. One code-mode script can run the whole cycle with snapshots kept out of the model context.

  • 378–419 msdecision latency in the live trace

  • ≤6,000characters of page text per request

Quick start

Point OpenCode at a local checkout. Zero runtime dependencies and no build step.

opencode.jsonc 
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["/path/to/jev-browser"]
}

Then run /jev-browse or just ask for browser work. Configuration and model resolution are in the README.
